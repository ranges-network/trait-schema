# Ontop Test
This directory contains an example of how to use Ontop to trainslate tabular data into turtle.

The tabular file contains four columns:
* occurrenceID
* body_mass
* tail_length
* total_length

After installing Ontop, the turtle is generated by running the command:
```
ontop-sqlite.sh -d ASUoccurrence.db -m ASUoccurrence.obda -o traits.ttl && \
cat traits.ttl punned-properties.ttl > punning.ttl
```
Note: Since this example uses sqlite as the data source, it is not possible to include the punninng information in in the odba file (i.e `ASUoccurrence.obda`). This a limitation of using sqlite. So, the turtle file `punned-properties.ttl` is appended to the `traits.ttl` file.

The `punned-properties.ttl` contains the punning statements:
```
asu:bodyMass    a owl:DatatypeProperty, owl:Class ;
                rdfs:subClassOf OBA:VT0001259 ;
                rdfs:label "body mass" .

asu:tailLength  a owl:DatatypeProperty, owl:Class ;
                rdfs:subClassOf OBA:VT0002758;
                rdfs:label "tail length" .

asu:totalLength a owl:DatatypeProperty, owl:Class ;
                rdfs:subClassOf OBA:VT0001256;
                rdfs:label "total length" .

asu:occurrenceID a owl:DatatypeProperty ;
                rdfs:label "occurrence ID" .
```

If the data source was more tradionitional relation database (eg., PostgreSQL), the punning information can be included in the odba file. An exmaple of is provided in `ASUoccurrence-punning.obda`.
