# YARRRML Test
This directory contains an example of how to use YARRRML to trainslate tabular data into turtle.

The tabular file contains four columns:
* occurrenceID
* body_mass
* tail_length
* total_length

After installing YARRRML, turtle that puns data properties as classes is generated by running the command:
```
map.sh mappings.yaml > punning.ttl
```
In punning.ttl, you see that `body_length`, `tail_length`, and `total_length` have been defined to be both a class and a data property.
```
<http://www.example.com/body_mass> <http://www.w3.org/1999/02/22-rdf-syntax-ns#type> <http://www.w3.org/2002/07/owl#DatatypeProperty> .
<http://www.example.com/body_mass> <http://www.w3.org/2000/01/rdf-schema#subClassOf> <http://purl.obolibrary.org/obo/OBA_VT0001259> .
<http://www.example.com/tail_length> <http://www.w3.org/1999/02/22-rdf-syntax-ns#type> <http://www.w3.org/2002/07/owl#DatatypeProperty> .
<http://www.example.com/tail_length> <http://www.w3.org/2000/01/rdf-schema#subClassOf> <http://purl.obolibrary.org/obo/OBA_VT0002758> .
<http://www.example.com/total_length> <http://www.w3.org/1999/02/22-rdf-syntax-ns#type> <http://www.w3.org/2002/07/owl#DatatypeProperty> .
<http://www.example.com/total_length> <http://www.w3.org/2000/01/rdf-schema#subClassOf> <http://purl.obolibrary.org/obo/OBA_VT0001256> .
```
To generate turtle in which the `tail_length` `inheres in` the `specimen`, run the follwoing command:
```
 map.sh tail_length_map.yaml > tail_length.ttl
 ```
